# 🛡 PromptShield AI

PromptShield AI is an AI Privacy Firewall that protects users before they send prompts to Large Language Models.

## Features

- Sensitive Data Detection
- Prompt Masking
- AI Privacy Score
- Risk Analysis
- Groq Llama Integration
- Prompt History
- Dashboard
- PDF Report

## Tech Stack

- Python
- Streamlit
- Groq API
- SQLite
- SQLAlchemy
- Plotly
- ReportLab
